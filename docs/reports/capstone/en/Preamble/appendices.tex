\section*{A.1 Catalog Schema, 8-Stage Knowledge Cleaning, and Consultation Tools}
\texttt{Retail-AI-} loads the Thanh Lam Mart catalog JSON (SHA-256 \code{3ab0666cb1b2efdc...}, 3,099 rows, 20 structured fields including \code{product_id}, \code{barcode}, \code{name}, \code{brand}, \code{price_vnd}, \code{sale_price_vnd}, \code{discount_promotion}, \code{stock}, \code{shelf}, \code{uom}, \code{image_url}, \code{category_hierarchy}) via a Pydantic validator, filtering 18 price-inconsistent rows (\code{sale_price_vnd > price_vnd}) and retaining 3,081 valid SKUs alongside a 13-aisle planogram.

The product knowledge enrichment pipeline combines 3,099 SSR product pages with EAN-13 barcode verification (333 exact barcode matches, 226 strict brand--form matches) and an 8-stage cleaning pipeline inspired by Hugging Face \code{datatrove}~\cite{hf_datatrove} and OpenFoodFacts~\cite{openfoodfacts} (Unicode NFC folding, invisible-character removal, HTML \code{<li>} period restoration, parenthesis balancing, cross-field separation, OCR noise filtering, and unverified allergen quarantine), reducing 4,606 Wave-1 raw defects to 0 post-clean defects (locked by 19/19 regression tests) and expanding across Waves~1--8 to cover 2,830/3,099 SKUs (91.32\%). \section*{A.2 LLM Tiering, On-Demand Vision, Supporting Speech Interface, and Complete Feature Matrix}
\begin{itemize}
    \item \textbf{Tiered LLM routing:} Lean streaming prose routes preferentially to low-latency streaming models (\code{qwen/qwen3.8-27b} $\to$ \code{openai/gpt-oss-20b/120b}, 6\,s timeout with automatic HTTP~429 failover) backed by DeepSeek (\code{deepseek-v4.1-flash:free} $\to$ \code{deepseek-v4.1-flash-1017}); complex structured JSON turns run on the bounded planner; Turn-1 semantic cache holds up to 256 entries (TTL 300\,s, Jaccard $\ge 0.88$, bypassing clinical/allergen queries).
    \item \textbf{On-demand \texttt{MobileNetV3Large-224} TFLite:} Distilled from \texttt{CLIP-ViT-B/32} (512-d) + \texttt{DINOv2-Small} (384-d) $\to$ SVD-256 (88.85\% variance); 7.04\,MB FP16 / 3.81\,MB INT8 + 1.58\,MB gallery (3,093 SKUs); Kaggle training (39.1\,min) with 4 losses; lazy-loaded at \code{POST /agent/respond/image}.
    \item \textbf{Supporting voice interface and deployment stack:} The Vue~3 + TypeScript client supports dual deployment: (i)~Vercel Singapore (\texttt{sin1}, \url{https://retail-ai-kiosk.vercel.app}) running client-side Silero VAD~v6, GTCRN WebAssembly SIMD denoising (192.3\,KB), STT-verified anti-echo barge-in, and direct browser $\rightleftarrows$ Azure Speech WSS (STT/TTS via 9--10 minute STS tokens at \code{/api/audio/azure-speech-token}); and (ii)~single-port Docker adding server WebSocket \code{/audio/transcribe/stream}, \texttt{DPDFNet2} ONNX (9.77\,MB), and local on-device \texttt{gipformer1.5-68M-rnnt} (69.8\,MB).
\end{itemize}

\section*{B.2 HITL State Machine and Persistence Stack}
All proposals persist in PostgreSQL (\code{proposals} table, SQLAlchemy + 6 Alembic migrations) following \texttt{PENDING} $\to$ \texttt{APPROVED} $\to$ \texttt{EXECUTED} (dispatching Mailpit/SMTP purchase orders or updating approved FEFO prices) or \texttt{REJECTED}/\texttt{REVISED}. Blind stock counts conceal book quantities during physical audits, negative-margin pricing triggers warnings, and \code{guard.py} verifies figures $\ge 1{,}000$ and flags \code{FALSE_EXEC} statements.
